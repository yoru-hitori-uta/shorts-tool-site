1. 本ツールについて

Shorts Publishing Tool（以下「本ツール」）は、YouTube チャンネル「夜、ひとりで聴く歌」の運営者（以下「運営者」）が、 自分のオリジナル曲のショート動画を運営者自身の YouTube チャンネルに投稿するためだけに使う個人用のデスクトップツールです。 一般の方が利用するサービスではなく、運営者以外のユーザーの情報を取得することはありません。

2. YouTube API Services の利用

本ツールは YouTube API Services を利用しています。本ツールを利用することで、 YouTube 利用規約（YouTube Terms of Service）に同意したものとみなされます。 また、Google によるデータの取り扱いについては Google プライバシーポリシーをご覧ください。

3. 取得する情報

本ツールが Google アカウントに求める権限は、次の1つだけです。

  • YouTube への動画のアップロード権限（OAuth スコープ https://www.googleapis.com/auth/youtube.upload）：運営者自身のチャンネルに動画をアップロードし、タイトル・説明文・公開設定・公開日時を設定するために使います。

本ツールは、上記の権限で得られる認証情報（OAuth のアクセストークンとリフレッシュトークン）と、 アップロードした動画の ID・公開日時を扱います。 視聴者の情報、コメント、再生データ、他のユーザーのアカウント情報、運営者の氏名・メールアドレスなどの個人情報は取得しません。

4. 情報の利用目的

取得した情報は、運営者のチャンネルへの動画の投稿と、投稿状況（未投稿・投稿済み）の記録のためだけに使います。

5. 保存場所と第三者への提供

  • 認証情報と投稿記録は、運営者のパソコンの中にだけ保存します。外部のサーバーやクラウドには保存・送信しません（動画のアップロード先である YouTube を除きます）。
  • 取得した情報を第三者に提供・販売・共有することはありません。
  • 本ツールおよび本サイトは、第三者による広告の配信を行いません。
  • 本ツールおよび本サイトは、Cookie や類似の技術を使ってユーザーの端末の情報を保存・取得することはありません。アクセス解析も行っていません。

6. アクセス権の取り消し方法

本ツールに与えた権限は、いつでも Google アカウントのセキュリティ設定ページ（サードパーティによるアクセス） から取り消すことができます。取り消した後は、本ツールは YouTube にアクセスできなくなります。 取り消しが行われた場合、本ツールが保存している認証情報と関連するデータは 30 日以内に削除します。

7. データの削除方法

  • 運営者のパソコンから認証情報のファイル（token.json）を削除すると、本ツールに保存されている認証情報は直ちに消去されます。
  • 保存されているデータの削除を希望する場合は、下記の連絡先までご連絡ください。ご依頼を受けてから 7 日以内に削除し、その旨をお知らせします。

8. お問い合わせ

本ポリシーに関するお問い合わせ・データ削除のご依頼：supercell70hero@gmail.com

9. 改定

本ポリシーを変更する場合は、このページで改定内容と最終更新日をお知らせします。

1. About this tool

Shorts Publishing Tool (the “Tool”) is a personal desktop tool used solely by the operator of the YouTube channel “夜、ひとりで聴く歌” (the “Operator”) to upload short videos of the Operator’s own original songs to the Operator’s own YouTube channel. It is not a public service and does not collect information about any user other than the Operator.

2. Use of YouTube API Services

The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. For how Google handles data, please see the Google Privacy Policy.

3. Information we access

The Tool requests only one permission from the Google account:

  • Permission to upload videos to YouTube (OAuth scope https://www.googleapis.com/auth/youtube.upload): used to upload videos to the Operator’s own channel and to set their title, description, privacy status, and publish time.

The Tool handles the credentials obtained through this permission (OAuth access and refresh tokens) and the IDs and publish times of the uploaded videos. It does not collect viewer information, comments, analytics data, other users’ account information, or personal information such as names or email addresses.

4. How we use information

The information is used only to upload videos to the Operator’s channel and to keep a record of upload status (not yet uploaded / uploaded).

5. Storage and sharing

  • Credentials and upload records are stored only on the Operator’s own computer. They are not stored on or sent to any external server or cloud service (other than YouTube itself, where the videos are uploaded).
  • We do not provide, sell, or share any of this information with third parties.
  • Neither the Tool nor this website allows third parties to serve content, including advertisements.
  • Neither the Tool nor this website stores, accesses, or collects information on or from users’ devices, including through cookies or similar technologies. No analytics are used.

6. How to revoke access

You can revoke the Tool’s access at any time from the Google security settings page (third-party access). After access is revoked, the Tool can no longer access YouTube. When access is revoked, we delete the stored credentials and related data within 30 days.

7. How to delete data

  • Deleting the credentials file (token.json) from the Operator’s computer immediately removes the credentials stored by the Tool.
  • To request deletion of stored data, please contact us at the address below. We will delete the data within 7 days of receiving the request and confirm the deletion.

8. Contact

For questions about this policy or to request data deletion: supercell70hero@gmail.com

9. Changes

If this policy changes, we will post the updated policy and its last-updated date on this page.
