# shorts-tool-site

「夜、ひとりで聴く歌」ショート投稿ツール（Shorts Publishing Tool）の紹介ページとプライバシーポリシー。
YouTube API Services の審査（Audit and Quota Extension Form）に提出する URL として GitHub Pages で公開する。

- `index.html` … トップページ（プライバシーポリシーへのリンクあり）
- `privacy.html` … プライバシーポリシー（日本語・英語）
- `terms.html` … 利用規約（日本語・英語）

このリポジトリにはツール本体のコードや認証情報（client_secret.json, token.json）を置かないこと。
