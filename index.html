このツールについて

Shorts Publishing Tool は、YouTube チャンネル「夜、ひとりで聴く歌」の運営者が、 自分で制作したオリジナル曲のサビ部分から歌詞付きの縦型ショート動画を作り、 運営者自身のチャンネルに予約投稿するための個人用ツールです。

About this tool

Shorts Publishing Tool is a personal tool used by the operator of the YouTube channel “夜、ひとりで聴く歌” (Songs to Listen to Alone at Night). It creates vertical short videos with lyrics from the chorus of the operator’s own original songs and schedules them for upload to the operator’s own channel only.

  • It is a desktop program that runs only on the operator’s own computer.
  • It is not a public service. No one else signs up or logs in, and it never accesses any other account or user’s data.
  • It uses YouTube API Services (YouTube Data API v3) to upload videos and set their title, description, and publish time.
